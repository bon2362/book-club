# Подборки книг

Подборка — набор до 50 опубликованных текстов каталога с названием, подписью автора и Markdown-описанием. Данные хранятся в `book_collections`, состав — в `book_collection_items`; `site_settings.id = collections_home_block_enabled` включает будущий блок на главной.

Статусы: `draft`, `pending`, `published`, `rejected`, `hidden`. Автор отправляет черновик с минимум двумя опубликованными текстами. Администратор публикует, отклоняет, отмечает проверенной, скрывает и возвращает из скрытых. Для отклонения и скрытия обязательна причина. После публикации изменения текста или состава снова видны модератору; простая перестановка книг не ставит подборку в очередь. Автор удаляет только неопубликованную подборку, администратор — любую.

`submitted_at` хранит время отправки, а `reviewed_snapshot` — последнюю проверенную версию для отображения разницы. Все записи идут через `withAuditContext` и триггеры миграции.

Публичные маршруты: `GET /api/collections`, `GET /api/collections/{slugOrId}`, `GET /api/collections/book-search`. Авторские: `/api/me/collections`; модераторские: `/api/admin/collections`. Ошибки API имеют поле `error`, а ошибки валидации — также `issues`.

`POST` и `DELETE /api/signup-books/{bookId}` меняют одну книгу, но используют общий `saveSignupSelection`; поэтому сохраняются правила активной сессии матчинга и рангов.

До применения `drizzle/0066_book_collections.sql` публичный список пуст, а мутации отвечают `migration_required` (409). Прод-миграцию применяет владелец после мержа PR.

Интерфейс: `/collections` показывает опубликованные подборки, `/collections/new` и `/collections/{id}/edit` дают автору редактор с автосохранением черновика. После публикации правки сохраняются явной кнопкой. На странице подборки запись меняет только выбранную книгу; для гостя намерение сохраняется до входа. Карточки подборки не показывают общий статус клуба. В профиле есть вкладка «Подборки». `GET /api/og/collections/{slug}` возвращает PNG для превью ссылки.
# Модерация

В админ-панели на вкладке «Подборки» есть очередь новых и изменённых подборок. Владелец может опубликовать, отклонить с обязательной причиной, отметить правку проверенной, скрыть с причиной, вернуть публикацию, отредактировать или удалить подборку. Подробнее: [админ-панель](../wiki/Admin-Panel.md).
