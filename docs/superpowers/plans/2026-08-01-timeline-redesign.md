# Лента времени: редизайн по дизайн-хендофу

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Привести `/timeline/[slug]` к виду и поведению из дизайн-хендофа:
полотно во всю ширину и высоту окна, тёплая поверхность, тихие метки,
раскладка без пропаж, легенда-фильтр — и перенести правку событий и эпох из
админки на саму страницу ленты.

**Два пул-реквеста.** PR 1 — задачи 1–6, вид и поведение. PR 2 — задачи 7–10,
правка на полотне. Задача 11 (сокращение админки) — отдельно, после обкатки.

**Architecture:** Правки точечные — почти весь целевой код в репозитории есть.
Меняются габариты страницы, оформление четырёх слоёв, логика раскладки в
`lib/timeline/geometry` и стартовый диапазон в `view-model.ts`. Добавляется
одна новая панель (легенда-фильтр). Геометрия остаётся чистой: измеритель
ширины текста передаётся параметром.

**Tech Stack:** Next.js App Router, React 18, CSS custom properties, Jest, Playwright.

**Источник:** `/Users/ekoshkin/Downloads/design_handoff_timeline/` —
`README.md` (спецификация), `DESIGN-RATIONALE.md` (обоснования),
`globals-additions.css` (токены), `prototype/` (референс).

## Шесть решений, принятых сверх хендофа

Хендоф принят целиком, кроме перечисленного. Каждое отклонение — с причиной.

1. **Существующие цвета типов мигрируются.** В базе лежат `#D97706`,
   `#2563EB`, `#009083` — именно они дают кричащие кружки. Новая палитра
   подействует только на типы, созданные после неё, поэтому три существующих
   обновляются разово на `--data-terracotta` / `--data-slate` / `--data-sage`.
   Без этого §2.4 хендофа не даст эффекта.

2. **Измеритель ширины текста передаётся параметром.** В прототипе ширина
   меряется `canvas.measureText`. Наша `lib/timeline/geometry` — чистые функции
   под Jest; в jsdom `measureText` вернёт ноль без нативного пакета, и раскладка
   схлопнется. Функция раскладки принимает `measure: (text, font) => number`:
   в браузере настоящий канвас, в тестах детерминированная оценка.

3. **Картинка — только по внешнему адресу.** Перетаскивание файла требует
   хранилища, которого в проекте нет. Рамка в карточке показывает картинку по
   `image_url`; поле адреса правится в админке, как у обложек книг. Настоящая
   загрузка — отдельная задача.

4. **Оболочка на всю высоту — только от 768 px.** Ниже страница остаётся
   обычной прокручиваемой: там вместо ленты вертикальный список на три десятка
   событий, и `overflow: hidden` его обрежет.

5. **Карточка растёт, полотно уступает.** Место под карточку зарезервировано
   (`min-height: 152px`), но описание бывает на два абзаца. Правило: карточка
   растёт до `40dvh`, дальше текст прокручивается внутри неё; полотно ужимается
   до своего минимума 200 px.

6. **Правка на полотне (§9–§11 хендофа) входит, но отдельным пул-реквестом.**
   Владелец подтвердил: из админки редактировать неудобно, и её роль должна
   сократиться. Работа делится надвое — **PR 1: задачи 1–6** (вид и поведение),
   **PR 2: задачи 7–10** (правка на месте). Причина деления не в объёме
   решений, а в проверяемости: если после мержа что-то поедет, по одному
   пул-реквесту на тысячу строк не понять, вид это сломал или редактор.
   Вид при этом доезжает до прода раньше и не ждёт редактор.

7. **Админская вкладка в этот заход остаётся.** Удалять работающий и
   протестированный редактор в том же PR, где появляется его замена, — неверный
   порядок: при шероховатости в новом редакторе владелец останется без обоих.
   Вкладка сокращается **следующей задачей**, после того как правкой на полотне
   реально попользовались. Это удаление на полсотни строк, не проект.

# PR 2: правка на полотне (задачи 7–10)

Основание — §9–§11 хендофа. Цель: завести, поправить, прикрепить и скрыть
элемент, не уходя со страницы ленты.

**Граница «общее против местного» — обязательна к отображению.** Событие живёт в
общей базе и попадает в несколько лент. Название, даты, тип, описание и картинка
— общие, правка меняет их везде. Заметка, цвет полосы эпохи и видимость —
свойства связи, только этой ленты. Без подписи в интерфейсе инлайн-правка
опасна: человек думает, что правит «здесь».

**Страница публичная.** Всё, что связано с правкой, показывается только админу,
и — критично — данные, которых нет в этой ленте («призраки»), **не должны
попадать в HTML для неавторизованного**. Проверять не только видимость кнопок,
но и состав ответа.
