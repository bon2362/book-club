# Календарь круга — дизайн-хендофф

Прототип к спеке `docs/superpowers/specs/2026-08-09-circle-calendar-design.md`.
Открыть: `Календарь круга.html` (React + Babel в браузере, сборка не нужна).

Файлы:
- `Календарь круга.html` — точка входа;
- `calendar.css` — вся вёрстка и токены (копия значений из `app/globals.css`);
- `data.jsx` — мок круга, участников, свободного времени, встреч;
- `grid.jsx` — сетка: закрашивание, наложение, тултипы;
- `app.jsx` — страница, попап клетки, состояния, панель Tweaks;
- `tweaks-panel.jsx` — только для прототипа, в продукт не переносится.

Панель Tweaks (шестерёнка справа) переключает сценарии, роль смотрящего и экран.
В продукте этих переключателей нет — они существуют, чтобы показать состояния.

## Отклонения от спеки

Все обсуждены и приняты владельцем проекта. Спеку стоит обновить.

1. **`TimezoneGate` не делается.** Вместо отдельного экрана первого захода — полоса
   сверху: «Время показано по Europe/Belgrade — определили по браузеру» + селект +
   кнопка «Верно». Не блокирует страницу. После подтверждения полоса остаётся в
   свёрнутом виде (галочка + пояс + селект).

2. **Назначить встречу можно только на полном пересечении.** Спека допускала
   назначение при неполном согласии. Решено: кнопка появляется только там, где всё
   время встречи свободно у **всех** участников круга. Серверная проверка при
   назначении — как в спеке, плюс эта же проверка полноты.
   *Следствие, которое стоит держать в голове:* если круг из пяти никогда не сойдётся
   целиком, назначить встречу через интерфейс будет нельзя вовсе.

3. **Отмена встречи — через диалог подтверждения**, а не сразу по кнопке. Текст диалога
   объясняет, что время освободится во всех кругах участников.

4. **Состав круга показывается целиком**, включая тех, кто ни разу не заходил
   («ещё не отмечался»). В avails видны только ответившие; у нас размер круга известен.

5. **Обрезка сетки по данным.** Дни без единой отметки скрываются, диапазон часов
   сжимается до фактического. Переключатель «Дни с отметками / Все дни подряд» —
   внизу календаря. В режиме «все подряд» окно по умолчанию 10:00–21:00,
   кнопка «Показать сутки» раскрывает 00:00–24:00.

6. **Наложение читается тоном, без рамок.** Частичные градации сжаты в светлую зону
   (α 0.10→0.38), полное пересечение — резкий скачок (α 0.62). Назначенная встреча —
   плотная заливка `--success-hover` + внутренняя белая линия, чтобы не путалась
   с верхней ступенью шкалы.

## Взаимодействие

### Закрашивание своего времени

- **Клик по клетке** — отмечает блок длиной встречи (60 мин = две получасовки).
  Сохраняется сразу, без кнопки.
- **Повторный клик** по своей клетке: если это не полное пересечение — снимает тот же
  блок; если полное — открывает попап.
- **Протягивание мышью** — закрашивает/стирает по одной получасовке (для подгонки краёв).
  Режим определяется первой клеткой: попал на свою — стираешь, на чужую — красишь.
- **Телефон:** короткий тап = то же, что клик; протягивание — после удержания ~320 мс.
  Пока идёт закрашивание, у сетки `touch-action: none`, иначе `pan-y`.

Сетка **не перестраивается** от собственных правок: набор дней и диапазон часов
считаются от состояния на момент загрузки. Иначе первое же закрашивание в пустом
круге схлопывало сетку в один день.

### Наведение на клетку

- полное пересечение → кнопка «Назначить встречу на 17:00»;
- всё остальное → тихий счётчик «3 из 5», без действия.

На телефоне тултипов нет — только попап по тапу.

### Попап клетки

Открывается по второму клику на своей клетке с полным пересечением, по клику на
встрече/занятом времени и по любому клику у того, кто не может редактировать.

Содержимое: дата, интервал, «свободны N из 5», построчно все участники — свободен /
занято другой книгой / нет отметки, и локальное время каждого («свободно · 20:00 у себя»).
Действия: «Назначить встречу на HH:MM» (только при полном пересечении на всю
длительность) и «Убрать своё время».

На десктопе попап позиционируется рядом с клеткой, на телефоне — нижний лист.

### Фильтр по участнику

Наведение (десктоп) или тап (телефон) на имя в правой колонке — сетка показывает
только его время одним тоном. Повторный тап снимает фильтр.

## Состояния (переключаются в Tweaks → Сценарий)

| Сценарий | Что показывает |
|---|---|
| Пусто | Никто не отмечался. Объяснение над сеткой, обрезка выключена, окно 10:00–21:00 |
| Закрашено | Есть наложение, встреч нет. Сетка развёрнута |
| Есть встреча | Карточка ближайшей встречи сверху, сетка свёрнута под «Назначить ещё встречу» |
| Только прошедшие | Свёрнутый список «Уже прошли» |
| Круг распался | Баннер, встречи видны, редактирование отключено |

Роль смотрящего: участник / аноним (только просмотр + баннер) / админ
(режим `?as=`, баннер про административный actor, действия за другого участника).

Заглушка «функция ещё не включена» (до прогона миграции) в прототипе не нарисована —
это простой текстовый экран, оформить по образцу баннера «Круг распался».

## Оформление

Только токены из `app/globals.css`. В `calendar.css` они продублированы в `:root`
исключительно чтобы прототип открывался автономно — **переносить этот блок в продукт не нужно**.

- Шкала наложения — `rgba(45,106,79,α)` от `--success`; α = 0.10 + 0.28 × доля свободных,
  полное пересечение — 0.62.
- Своё время — треугольный уголок 8 px в левом верхнем углу **первой** клетки отрезка,
  `rgba(30,77,57,.85)`. Один уголок на непрерывный отрезок, не на каждую получасовку.
- Занято другой встречей — штриховка `--accent` под 135°.
- Встреча круга — заливка `--success-hover` + `inset 0 0 0 1px rgba(255,255,255,.55)`,
  подпись времени белым в первой клетке.
- Линии сетки: только часовые (`--hair-soft`), получасовых нет. Вертикали — между днями.
  Разрыв в датах (при обрезке) — колонка 9 px с одной линией.
- Клетка — 22 px на десктопе, 26 px на телефоне. Ширина колонки — `minmax(0,1fr)`.
- Карточки — `--radius-card`, кнопки — `--radius-control`, тени — `--shadow-card` / `--shadow-pop`.

## Что осталось за прототипом

- заглушка до миграции;
- поведение при 20+ участниках (у нас круг 3–5, шкала на это и рассчитана);
- редактирование слага админом;
- копия ссылки — убрана осознанно, адрес есть в строке браузера.

## Открытые вопросы к реализации

1. Сетка считается на клиенте из интервалов, приходящих с `GET /api/calendar/[slug]`.
   Кандидаты (окна, где свободны все на всю длительность) в прототипе тоже считаются
   на клиенте перебором 28 дней × 48 получасовок — на таких объёмах это дёшево,
   но `lib/calendar/overlap.ts` всё равно нужен для серверной перепроверки при назначении.
2. При смене длительности встречи набор кандидатов меняется мгновенно. Если длительность
   меняет один участник, у остальных она подтянется только после перезагрузки —
   это согласуется с решением «без realtime», но стоит явно проговорить в UI-тексте.
