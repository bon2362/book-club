# Подборки книг

Подборка — тематический список книг каталога, который участник собирает и отправляет владельцу на проверку. Пока готов только слой данных и API; пользовательский экран появится в следующих PR.

Автор начинает с черновика, добавляет минимум две опубликованные книги и отправляет подборку. Владелец может опубликовать, отклонить с причиной, скрыть с причиной или отметить новую версию проверенной. После публикации автор не может удалить подборку, но может предложить изменения; перестановка книг отдельно не требует новой модерации.

Данные находятся в Neon Postgres: `book_collections`, `book_collection_items` и `site_settings`. Перед использованием на production после мержа нужно применить миграцию:

```bash
node --env-file=.env.local scripts/apply-migration.mjs drizzle/0066_book_collections.sql
```

До миграции публичный список безопасно пуст, а запись возвращает сообщение, что функция ещё не включена.
